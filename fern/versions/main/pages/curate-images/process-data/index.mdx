# Process Data for Image Curation

Process image data you've loaded from tar archives using NeMo Curator's suite of tools. These tools help you generate embeddings, filter images, and prepare your dataset to produce high-quality data for downstream AI tasks such as generative model training, dataset analysis, or quality control.

## How it Works

Image processing in NeMo Curator follows a pipeline-based approach with these stages:

1. **Partition files** using `FilePartitioningStage` to distribute tar files
2. **Read images** using `ImageReaderStage` with DALI acceleration
3. **Generate embeddings** using `ImageEmbeddingStage` with CLIP models
4. **Apply filters** using `ImageAestheticFilterStage` and `ImageNSFWFilterStage`
5. **Save results** using `ImageWriterStage` to export curated datasets

Each stage processes `ImageBatch` objects containing images, metadata, and processing results. You can use built-in stages or create custom stages for advanced use cases.

## Image diagnostics without filtering

`ImageDiagnosticsStage` annotates each image's metadata with dimensions, sharpness,
and QR coverage. It keeps every image and preserves batch order. Install the
`image_cpu` extra and supply native-resolution `uint8` RGB arrays in `image_data`.

```python
from nemo_curator.stages.image.diagnostics import ImageDiagnosticsStage

stage = ImageDiagnosticsStage()
stage.setup()
annotated_batch = stage.process(image_batch)
```

| Metadata field | Meaning |
| --- | --- |
| `image_width`, `image_height` | Decoded pixel dimensions. |
| `image_sharpness_score` | Grayscale Laplacian variance (`CV_64F`, kernel size 1). |
| `image_qr_area_ratio` | Detected QR quadrilateral area divided by image area, capped at 1. |
| `image_sharpness_status`, `image_qr_status` | `ok`, `compute_error`, or `decode_error`. Failed measurements are null. |

QR detection does not require decoding the QR text. No detections gives zero;
overlapping quadrilaterals can double-count area before the cap. Sharpness depends
on resolution and texture; it is not a universal quality score.

The input decoder controls frame selection, orientation, and transparency. The
optional `decode_image_rgb(encoded_bytes)` helper selects frame zero, applies
EXIF orientation, composites transparency over white, and returns RGB pixels
without resizing. Record that policy and library versions when comparing scores.
